# Щебетарь (Chirper)

Локальная диктовка для macOS: зажмите правый ⌥ Option, произнесите текст и
отпустите клавишу — расшифровка появится в активном приложении. Голос
обрабатывается на компьютере и не отправляется в облако.

## Возможности

- локальное распознавание русской речи через GigaAM v3 `e2e_rnnt`;
- нативная оболочка на Swift — правильные имя, иконка и разрешения macOS;
- глобальный push-to-talk хоткей и вставка в любое приложение;
- индикатор записи в строке меню и поверх полноэкранных окон;
- история последних 20 расшифровок без сохранения аудио;

## Установка готового приложения

Готовый `Chirper.app` уже содержит Python runtime, ONNX Runtime и остальные
зависимости. Пользователю не нужно устанавливать Python, Xcode или Homebrew.

Скачайте DMG со страницы
[Releases](https://github.com/chetkinalexandr/chirper/releases/latest).

1. Откройте `Chirper-1.4.0-arm64.dmg`.
2. Перетащите Chirper в Applications.
3. Разрешите первый запуск — сборка не нотарифицирована Apple, поэтому
   macOS её сначала заблокирует:
   - **macOS 15 и новее:** запустите приложение двойным кликом, затем
     откройте **System Settings → Privacy & Security**, найдите внизу
     сообщение о блокировке Chirper и нажмите **Open Anyway**.
   - **macOS 13–14:** нажмите по приложению правой кнопкой и выберите
     **Открыть**, затем подтвердите **Открыть** в диалоге.
4. Разрешите Chirper доступ к Microphone и Accessibility.

При первом запуске потребуется интернет: приложение скачает закреплённую
ревизию GigaAM v3 `e2e_rnnt` (int8) размером около 216 МБ. Дальше
распознавание работает локально.

Готовая сборка поддерживает Apple Silicon и macOS 13 или новее.

## Сборка из исходников

- macOS 13 или новее;
- Python 3.10+;
- Xcode Command Line Tools (`xcode-select --install`);
- около 2 ГБ для окружения и модели;
- разрешения Microphone и Accessibility.

Проект рассчитан на Apple Silicon. На Intel зависимости могут потребовать
другие сборки ONNX Runtime.

```bash
cd chirper
python3 -m venv .venv
.venv/bin/pip install --upgrade pip
.venv/bin/pip install -r requirements.txt
./собрать_app.sh
open dist/Chirper.app
```

Сборка не изменяет `/Applications`. Для локальной установки или создания DMG:

```bash
./собрать_app.sh --install
./собрать_app.sh --dmg
```

Имя DMG формируется из версии приложения и архитектуры, например
`dist/Chirper-1.4.0-arm64.dmg`.

Для автозапуска добавьте `/Applications/Chirper.app` в **System Settings →
General → Login Items**.

## Приватность

Во время диктовки нативная оболочка создаёт временный WAV и удаляет его сразу
после распознавания. История ограничена 20 записями и хранится в
`~/Library/Application Support/Chirper/history.json`. Модель загружается из
Hugging Face, но распознавание выполняется локально.

## Архитектура

Нативный `Chirper` владеет меню-баром, хоткеем, микрофоном, оверлеем,
буфером обмена и системными разрешениями. Он запускает встроенный автономный
воркер `ChirperASR`, который содержит Python runtime, один раз прогревает
GigaAM и принимает запросы через JSON Lines. Системный Python не используется.

В исходниках остались только файлы, нужные для этой схемы:

- `native/Chirper.swift` — интерфейс и интеграция с macOS;
- `asr_worker.py` — протокол фонового воркера и чтение WAV;
- `asr.py` — загрузка GigaAM (ONNX int8) и нарезка длинного аудио;
- `собрать_app.sh` — сборка `.app`, локальная установка и DMG.

## Ограничения

- основной движок оптимизирован для русского языка;
- английские имена, сокращения и профессиональные термины могут распознаваться
  с ошибками;
- готовая сборка предназначена для Apple Silicon;
- приложение подписано ad-hoc и не нотарифицировано Apple, поэтому первый
  запуск требует ручного подтверждения в **Privacy & Security** (см.
  «Установка готового приложения»).
